# Contributing

Contributions should preserve the project's authorization boundaries and must not add real credentials, private keys, device identities, customer data, or generated installers.

Before opening a pull request:

1. Run the relevant tests in the component you changed.
2. Run `git diff --check`.
3. Confirm that `.env`, runtime state, `node_modules`, `dist`, and binaries are not staged.
4. Describe security, platform, and deployment impacts.

By submitting a contribution, you agree that it is provided under Apache-2.0 unless you state otherwise in writing.
