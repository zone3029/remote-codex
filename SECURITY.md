# Security policy

Read the full [disclaimer and acceptable-use boundary](DISCLAIMER.en.md) before testing or deploying this project.

Use Remote Codex only on systems and networks where you have explicit authorization. Never report a live token, password, private key, device identity, or customer data in a public issue.

To report a vulnerability, email **302911425@qq.com** with:

- a short description and affected component;
- reproducible steps or a minimal proof of concept;
- impact assessment and suggested mitigation.

Please allow reasonable time for triage before public disclosure. Do not test against infrastructure you do not own or administer. Do not attempt to verify suspected abuse by accessing, damaging, or expanding the impact of a system.
